## 6. 符甲虫

从第8波逐步加入，以约5.5%比例替换普通怪，后期约8.5%；计入既有敌人总上限，不额外叠加实体名额。早期最多3只、后期最多5只。像素甲壳轮廓、防御姿态、方向走廊与冲刺动作可辨认。

行为：慢速接近 → 0.7秒防御 → 0.85秒锁定方向预警 → 0.42秒短突进 → 1.05秒恢复。普通移速为同级史莱姆0.84倍、生命1.3倍；防御仅减伤35%，没有无敌；突进速度360，名义距离约151，不追着玩家瞬间转向。恢复后重新接近，避免连续冲撞。

复用敌人池，状态在取出时重置；接入相同碰撞、直伤/燃烧/暴击、击退、金币（普通2）、能量、击杀、音效、命中/死亡反馈和暂停。测试覆盖出生比例/上限、有限减伤、锁定方向、可受伤、恢复和对象池复用。
