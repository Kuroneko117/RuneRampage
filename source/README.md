# 术式过载 V0.2

既有 Cocos Creator 3.8.8 + TypeScript 工程，入口仍为 `assets/scenes/Main.scene`。工程现位于 `D:\项目\RuneRampage`，项目/场景 UUID、引擎配置、竖屏与微信构建配置保留。

## 运行

使用现有 `Open-Project.cmd`，或在 Cocos Creator 3.8.8 打开此目录。等资源导入后打开 Main 场景并预览。游戏 UI 在运行时创建，编辑态场景只看到原 Canvas/Camera 属正常。

主菜单点击“开始游戏”；手机拖动左下摇杆，电脑先点击画面再用 WASD / 方向键。法术自动瞄准最近敌人。死亡后点击“重新开始”或“返回主菜单”；Enter 可开始、重开或继续波次。

## 完整循环

开始 → 25 秒战斗 → 击败史莱姆/蝙蝠 → 金币掉落并自动吸附 → 波末暂停并进入魔法商店 → 轻点商品卡购置或升级 → 继续下一波 → 死亡结算。

- 金币只用于当局商店，没有背包；史莱姆掉 2 金币，蝙蝠掉 1 金币。
- 波末自动结算场上剩余金币，避免暂停后丢失奖励。未击败敌人不奖励金币，进入下一波时清场。
- 玩家生命 5；接触伤害 1、0.95 秒无敌与受伤反馈。商店不回血；购买后立即生效，继续时保留生命、金币和装备，玩家回到场中。
- 切后台暂停并清空输入。最高记录只保存在本机（波次优先，同波次比较击败数）；当局金币、装备不跨局保存。

## 打击反馈与性能

敌人闪白、轻微抖动和击退；死亡缩放淡出加四个几何粒子；伤害数字飘字限额并合并同目标密集命中；金币有弹起、轻微旋转、吸附和拾取提示。震屏仅用于爆炸或强攻击，持续最多 0.12 秒，不调用手机持续振动。

轻微 hit stop 仅暂停约 0.025 秒的角色位置呈现，并限制触发频率；60 Hz 战斗模拟、计时、输入和碰撞继续运行。没有通过全局暂停、降低逻辑时间或暂停波次实现顿帧。

模型对象与绘图节点复用：敌人、子弹、金币、爆炸、死亡特效、飘字。逻辑上限：敌人 48、子弹 48、金币 64、待触发爆炸 16；金币上限合并金额，不丢奖励。画面上限：死亡动画 12、特效组 20（四粒子的消散组与爆炸环共享限额）、飘字 12。HUD 每 0.1 秒更新。

`RuneRampage.setFeedbackHooks({ hit, explosion })` 提供命中/爆炸音效接口，默认静音，无音频资源和插件。后续短音效适配器可以在此接入，不影响战斗逻辑。`getDiagnostics()` 提供数量与复用池统计，不在玩家界面展示。
