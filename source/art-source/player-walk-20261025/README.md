# 术士行走：可编辑分层关键帧源

制作日期：2026-10-25 至 2026-10-26。仅改进现有角色行走；保持 Cocos Creator 3.8.8、112 高逻辑显示尺寸、80×88 帧画布、脚底锚点 `(0.5, 0.125)`。

## 来源与制作方式

- `reference.png` / `reference-large.png`：从本工程原 `player_idle_02` 无损还原的角色身份参考，沿用工程原有美术来源与许可记录；不新增第三方下载素材。
- `generated-walk-sheet.png`：内置 `image_gen.imagegen` 第一轮生成，输入原人物参考。4×3 透明行走草稿，1448×1086。头脸/法杖和相位漂移，**不直接进入运行包**。
- `revised-walk-sheet.png`：同一内置工具第二轮编辑，输入第一轮图与原人物参考，要求左右交替、固定腰线、首尾闭环。仍只作为分层制作源，**不直接进入运行包**。
- 没有使用付费 API、ComfyUI 模型下载或新增插件。内置工具没有暴露模型版本/seed，因此不编造这两项信息。
- `layer-fixed-identity.png` / `layer-robe-hem.png`：原角色头、上身、手杖及下摆的分层导出。`layer-boot-front.png`：从第二轮草稿提取并归一化的新靴子图层。
- `walk-keys.json`：12 相位可编辑关键帧，包括两脚的坐标、足底线、形状、角度与下摆跟随。两脚相差半周期，支撑脚地面不变；抬脚最多6源像素、前送3源像素，局部下摆抬起最多4源像素。不是把整张人物图平移成12张，也不是宣称12张全部重新手绘。
- `tools/prepare-player-walk.py`：切片、分层、关键帧烘焙及联系表/GIF导出。`tools/pack-player-walk.py`：只量化新步态到原图集调色板，重排图集并更新目录。原有其他人物/敌人/UI像素不改。

## 工具提示词记录

第一轮：以原人物为精确身份参考，生成4列3行透明12帧原地快走；银发、紫兜帽、金边短法袍、右手紫球法杖不变；左右脚交替，袍摆跟随；无文字、无地板、无符文光圈；固定大小、足底与腰线；01左支撑、07右支撑、12衔接01。

第二轮：编辑第一轮，保持造型与4×3结构，纠正过多相似右脚姿态。明确01–06为左脚落地至右脚前送/落地，07–12为右脚落地至左脚前送/落地；要求靴子在80×88尺度清晰、抬脚约3像素、末帧接近首帧。实际输出仍未达到直接导入标准，最终采用上述分层关键帧整理。

精确工具调用与提示词保存在本次 Codex 会话。此文件记录选用/拒用原因，不把生成稿当已通过的成品。
