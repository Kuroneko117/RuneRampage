## 改动与原因

| 项目 | 原因 | 本轮调整 |
|---|---|---|
| 商店锁定 | 用户要求删除 | 删除按钮、触区、文字、锁定字段/方法/费用与跨波保留逻辑。每波与付费刷新更新全部未满级商品；刷新20/40/80递增、稀有商品、购买/强化/祝福保持。整张商品卡片可点购 |
| 玩家一闪一闪 | 受伤时循环切全白帧、94%/100%缩放、200/255透明度；高攻速反复在idle/cast姿势间跳；全局命中顿帧还暂停玩家与弹体显示位置 | 本体保持固定缩放和不透明，删除受伤白闪；无敌时间仍有效，仅用脚下青色符文表示。连续idle/move时钟，施法只保留小型杖端光；过载沿用原美术。强暴击仅对被击中敌人作18ms短停，最多约0.45秒一次，玩家/弹体/相机保持跟随 |
| 爆裂和燃烧遮怪 | 持续燃烧挂着64×64爆炸贴图，原命中/死亡大光团位于怪物和危险层上方 | 燃烧改12×12脚边小标记；命中/死亡粒子基准30→16，缩短寿命并合并近距离重复特效。友方反馈置于角色和怪物下方，敌方粉色预警/弹体仍在前。爆裂用0.18秒低透明度空心地面波纹，伤害范围不变 |
| 地图太大 | 2100×3600，走位空间松散、边界离战斗较远 | 改1440×2160，面积约原41.14%（缩小58.86%），宽/高分别缩小31.43%/40%。正常移速横穿约6.5秒、纵穿约9.8秒。沿用原地图图像，边缘装饰24→16 |
| 比例与边缘 | 原角色中心锚点让脚底伸出小地图边界；镜头一直居中会露出大块场外区域 | 玩家显示112、普通怪60–68、远程82、精英82×1.4、Boss82×2.4。地面单位按脚底对齐，飞行怪/甲虫保持中心；镜头接近边界渐停，给角色上方和两侧留显示余量。碰撞半径、速度、攻击判定不变 |
