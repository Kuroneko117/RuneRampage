# 术式过载 体验品质整改

日期：2026-10-28。引擎 Cocos Creator 3.8.8；基线 `6a5dd6c`；开发分支 `codex/quality-polish-20261028`。原微信包及配置备份见 baseline.json。

用户已授权自行复盘与优化，本轮不再把此前四卡商店当成已通过的目标。保留魔法像素美术、25秒波次、八装备/经济、单手手动过载、Boss混战、20波与无限、离线存档与微信配置。

## 观察与取舍

- 实际393×852基线中商品名/效果约12px，图标约22px，主次按钮与商品信息争夺空间。
- 上次纵向清单也被用户否决。选择保留四商品同时比较，但重新安排图标、文字、价格和操作；不只改按钮色。四行清单更能放长文本，当前先不重复已否决方案。
- HUD顶部容器和底部说明偏重。保留现有安全区和操作边界，提升生命/波次/倒计时的可辨识度，减少常驻操作说明，不用整屏色框。
- 战场背景地面纹样接近前景明度。采用同一原地图降低对比，保留轮廓而不换场景；危险预警优先于金币、友方特效。
- 敌人类型赋色在同一函数内被白色覆盖，修正赋色顺序；精英/远程/快怪除颜色外保留实际造型与标记。普通史莱姆与蝙蝠不换成新美术。
- 手动过载图标存在两套异步贴图绑定竞争：同一Sprite先加入BattleArt等待队列，又绑定独立OverloadArtwork，后完成者覆盖先完成者。必须单一来源，失败时允许明确回退。

## 视觉规范

暗蓝石质底、冷白正文、金色价格、紫色稀有、青蓝主要行动。卡片使用已有九宫格与图集，避免新增大图。标题40，商品名30，效果26，等级22，购买字26（720宽设计坐标）；64图标。卡片306×320，2×2，购买视觉90、触控132。继续按钮仍是最高权重。已购买状态保留所购效果，明确停用，不能看起来是空商品。未满足条件的高级动作继续隐藏。

商店信息顺序：结束波次/金币 → 商品名称与稀有/等级 → 下一等级效果 → 独立价格购买 → 刷新/强化 → 继续下一波。属性留在独立查看页，不回填长篇解释。

主菜单减少多个同等强度入口，放大既有术士与符文识别；开始游戏最高对比，其次模式，图鉴/纪录等低权重，保留全部真实可用入口。无新手引导、锁定、假排行或假广告入口。

## 本轮验证范围

1. 先保留首页、5秒战斗、商店基线；实际Cocos预览验证修改后画面和购买/不足/售出/稀有/强化/属性状态。
2. 检查320×568、360×800、393×852、412×915、768×1024，安全区/胶囊与触控区不交叠。
3. 修复确定性逻辑问题并先复现失败：Boss安全出生、首格可负担候选、对称连锁、燃烧末跳。
4. 回归25秒Boss结算、20波胜利/无限、单手操作/暂停/前后台、音频切换、池上限与存档。
5. 独立评鉴者运行输入试玩和截图，分清状态定位测试与自然试玩；微信release重新构建测实际字节，不宣称桌面性能等于真机。

不新增角色、装备数量、网络、支付或复杂插件。本轮所有画面方案为自主判断，需最终运行画面复核，不能以实现或文档完成代替验收。

## 2026-10-29 最终收敛

独立美术审查后来实际获取并查看了官方Steam战斗截图，来源与观察见visual-direction.md；未找到可验证的官方商店图，不编造竞品商店分析。视觉验收见final-visual-review.md。

短屏商店增加1080高的紧凑排布，按可用安全区域缩放：卡片306×270，名称34、收益28、购买30设计字号，触控高110；常规长屏仍用原2×2排布。320×568在注入胶囊/刘海/底部手势区后，商品名约13px、收益约12px，不再把整页1280高压成约9px。五种尺寸的两页商店按钮均实测至少44CSSpx、无交叠、在模拟安全区内；这些是浏览器触控模拟数据。

暂停112平方触控，设置/确认132高；按下仅缩放文字，保持原生Button命中矩形不变，避免按钮边缘松手被取消。金币列与暂停分开，极大数值禁止换行并自动缩字；属性页仍可查看实际数值。

压力画面中普通/暴击数字23/28设计字号，移除反复的“暴击/爆裂”前缀，以大小与颜色区分；危险时寿命降到0.42秒，仍保留OVERLOAD。实测池上限不变，未通过增加资源和粒子填补体验。
